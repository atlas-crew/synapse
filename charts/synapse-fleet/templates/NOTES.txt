Synapse Fleet chart installed.

The API service is exposed through the release name generated by Helm.

Default health endpoints:
- `GET /health`
- `GET /ready`

The Fleet API requires one of `database.url`, `database.existingSecret`, or
`secrets.existingSecret` to be set before the release can start.
The job queue is disabled by default; enable it only when Redis is configured.

If you rely on generated secrets, prefer server-side `helm install` /
`helm upgrade`. Client-side renderers and GitOps controllers that template the
chart without a live cluster will regenerate those secrets on each render.
For GitOps flows, point `secrets.existingSecret` at an operator-managed Secret.

If you enabled `migrations.enabled`, Prisma migrations run as a Kubernetes Job
using the Fleet image and the same runtime environment. Hook mode is enabled by
default so migrations run before upgrades by default.

If you enabled `ui.enabled` or set public UI URLs, the chart also renders
companion `ConfigMap` / `Secret` resources for a standalone dashboard build.

Run `just helm-validate` from the repository root to lint and template the chart workspace.
